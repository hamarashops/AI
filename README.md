# Hamarashops Project

This is a full-stack project with a Java backend and a React/Vite frontend.

---

## Tech Stack

*   **Backend**: Java
*   **Frontend**: React, Vite, JavaScript

---

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

*   [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/)
*   [Node.js and npm](https://nodejs.org/)

### Backend Setup (`untitled` directory)

1.  Navigate to the source directory:
    ```bash
    cd c:\AI\Hamarashops\untitled\src
    ```
2.  Compile the Java code:
    ```bash
    javac main\java\org\example\Main.java
    ```
3.  Run the application:
    ```bash
    java org.example.Main
    ```

### Frontend Setup (`client` directory)

1.  Navigate to the client directory:
    ```bash
    cd c:\AI\Hamarashops\client
    ```
2.  Install the dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm run dev
    ```
    Then open your browser to the URL provided (e.g., `http://localhost:5173`).
